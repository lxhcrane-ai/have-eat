## 关键行为差异

- **微调期（peak）**：HYD-01（脱水百分比）被抑制，因为赛前水盐操作会让这个数值必然异常；水合改由 HYD-05（补液计划执行率）判定。ENE-01（能量盈亏）关闭——微调期不动热量缺口是阶段定义本身。
- **恢复期（recover）**：HYD-01/02/03、ENE-01、PHASE-01、REC-03 全部抑制；改看 HYD-04（称重后补液）、REC-01（碳水与进食节奏）、REC-04（体重回升）。晨脉在称重后生理性偏高，不参与判断。
- **同一份数据、两套结论**：scripts/test-phases.js 用"脱水 3.7% + 蛋白 96g + 酸痛 8 + 次日速度课 + 睡眠 6h"验证，cut 期产出 HYD-01/PRO-01 等 7 条告警，peak 期不报 HYD-01/PRO-01，改报 HYD-05 与 LOG-01，评分差 ≥ 8。

复现：`node scripts/test-phases.js`（47 项断言）。
