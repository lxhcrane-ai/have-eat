# 阶段叠加执行细节（草稿）

> **状态：草稿，待营养师审。**
> 本文件不是规则、不进入规则引擎，也不改变 `miniprogram/data/goalMatrix.js` 的任何阈值。它只把 `MX-*` 格子和 `C*` 配方翻译成可照着排的餐次与执行动作。
> 口径：与矩阵冲突时，以 `miniprogram/data/goalMatrix.js` 与 `docs/goal-matrix.md` 为准；本文件不另立阈值。
> 证据：数值只来自矩阵格子和已核实 KB 条目（`pro-*`、`carb-*`、`hyd-*`、`wc-*`、`RC-*`、`RF-*`、`TN-*`）。矩阵标 `weak` 的格子只给方向，不给克数、千卡、小时数。
> 适用：拳击运动员日常与专项营养；阶段由营养师设定，日志只做确认/反证。

## 0. 通用骨架（四阶段都适用）

1. 餐次：3 餐 + 1–2 次加餐；蛋白 0.3–0.4 g/kg/餐，分到 3–5 餐（`pro-spread`）。
2. 训练前：主餐放在训练前 1–3 小时；碳水 1–2 g/kg（`carb-timing`）；速度课按 2–3 小时（`MX-*-P-SPD`）。
3. 训练后：2 小时内蛋白 25–40 g（`pro-timing`）；高负荷或两练按 1.0–1.2 g/kg/h 补糖（`carb-recovery`）。
4. 睡前：睡前 3 小时不大量进食；咖啡因睡前 8 小时避免（`MX-*-G-SLE`）；需要时睡前蛋白 30–40 g（`pro-spread`）。
5. 绝对时间点只作示例：把“训练前 3 小时”平移到实际训练时间，不把示例当处方。

**相对时点示例（只示范关系，不是时刻处方）：**

| 相对时点 | 餐次结构 | 依据 |
|---|---|---|
| 训练前 3–4h | 正常主餐：蛋白 0.3–0.4 g/kg + 主食 + 蔬菜 | `pro-spread` |
| 训练前 1–3h | 碳水 1–2 g/kg，低纤维低脂 | `carb-timing` |
| 训练后 0–2h | 蛋白 25–40 g；耐力/两练加碳水 1.0–1.2 g/kg/h | `pro-timing` / `carb-recovery` |
| 训练后 2–4h | 正餐：蛋白 + 碳水 + 蔬菜 | 定性 |
| 睡前 3h | 不大量进食；需要时睡前蛋白 30–40 g | `MX-*-G-SLE` / `pro-spread` |

## 1. maintain（维持期）

### 1.1 矩阵对应

| 当天课型 | 矩阵格子 | 宏量 | 时机 / 备注 |
|---|---|---|---|
| 力量 / 爆发 | `MX-MAINTAIN-P-POW` | P 1.6–2.2；C 4–6 g/kg；E ±350 kcal | 训练前 1–3h 碳水 1–2 g/kg；训练后蛋白 25–40 g |
| 速度 | `MX-MAINTAIN-P-SPD` | P 1.6–2.2；C 4–6 g/kg；E ±350 kcal | 训练前 2–3h 碳水 1–2 g/kg；咖啡因按需 |
| 增肌 | `MX-MAINTAIN-P-HYP` | P 1.8–2.2；C 4–6 g/kg；E +200~+400 kcal | 训练后蛋白 25–40 g；训练后碳水 1.0–1.2 g/kg/h |
| 有氧耐力 | `MX-MAINTAIN-P-END` | P 1.6–2.2；C 4–7 g/kg；E ±350 kcal | 训练后碳水 1.0–1.2 g/kg/h；两练间隔≥6h |
| 肌耐力 | `MX-MAINTAIN-P-MEND` | `macros=null`（weak） | 训练前留出消化时间；具体时点与份量由营养师确认 |
| 技战术 | `MX-MAINTAIN-P-SKL` | `macros=null`（weak） | 不空腹；训练前少量碳水，具体量由营养师确认 |
| 控级别 | `MX-MAINTAIN-B-HOLD` | P 1.6–2.2；C 3–5 g/kg；E ±350 kcal | 正常三餐；每周看体重斜率 |
| 增重 | `MX-MAINTAIN-B-GAIN` | P 1.8–2.2；C 4–6 g/kg；E +200~+400 kcal | 仅非赛季且距称重>84 天；训练后蛋白 25–40 g |

### 1.2 三餐与训练前后怎么排

- **单次训练日**：早餐保证蛋白；训练前 1–3 小时吃主餐（碳水 1–2 g/kg）；训练后 2 小时内补蛋白 25–40 g；晚餐正常吃；睡前 3 小时不大量进食，需要时加 30–40 g 蛋白。
- **力量 / 爆发日**：训练前 1–3 小时碳水 1–2 g/kg；训练后蛋白 25–40 g。若当天另有耐力或第二练，训练后按 1.0–1.2 g/kg/h 补糖。
- **速度日**：训练前 2–3 小时吃 1–2 g/kg 碳水，选低纤维低脂；速度课前不安排大容量；咖啡因按需，睡前 8 小时避免。
- **耐力日**：碳水 4–7 g/kg；训练后 1.0–1.2 g/kg/h 补糖；两练间隔至少 6 小时。
- **肌耐力 / 技术日**：不空腹；训练前留出消化时间吃少量易消化碳水；训练后按常规吃蛋白和碳水。矩阵标 weak，不在这里给具体克数或小时数。
- **控级别日**：碳水 3–5 g/kg，能量 ±350 kcal，正常三餐；不需要为“维持”额外加餐，也不要偷偷制造缺口。
- **增重日**：只在非赛季且距称重超过 84 天时开；能量 +200~+400 kcal，蛋白 1.8–2.2 g/kg；训练后蛋白 25–40 g。

### 1.3 保肌 / 保能力要点

1. 蛋白总量 1.6–2.2 g/kg，分到 3–5 餐，每餐 0.3–0.4 g/kg；不要只在晚餐集中吃。
2. 碳水按当天课型取：力量/爆发/增肌 4–6 g/kg，耐力 4–7 g/kg，控级别 3–5 g/kg。
3. 能量维持 ±350 kcal；不要把“维持”执行成隐性减脂。
4. 增重目标只在非赛季且距称重>84 天时开；距称重不足 12 周转 `B-HOLD` 加力量维持。
5. 维持期不额外加有氧；力量课保强度，容量适中。

### 1.4 什么信号出现就要加餐

- 体重连续两周偏离维持带（`PHASE-02`）：先看 7 日移动平均，再决定加/减 200 kcal 左右，具体由营养师定。
- 睡眠 <6.5 小时（`SLE-01`）：先补睡眠，不靠加餐或咖啡因硬顶。
- 酸痛 ≥7（`REC-02`）：降强度/容量，训练后蛋白和碳水照常。
- 晨脉比基线高 ≥5 次/分（`REC-03`）：减载，检查能量与补水。
- 能量可用性（EA）<30 kcal/kg FFM（`G-EA`）：不许再加深缺口；先加能量，必要时转诊。

### 1.5 常见错误

- 把“维持期”当成“随便吃”，或反过来偷偷减。
- 增肌期同时叠太多有氧，能量盈余被吃掉。
- 技术课空腹上，靠咖啡因撑。
- 蛋白只在晚餐吃，单餐 0.3–0.4 g/kg 分配做不到。

## 2. cut（减脂期）

### 2.1 矩阵对应

| 当天课型 | 矩阵格子 | 宏量 | 策略 / 时机 |
|---|---|---|---|
| 力量 / 爆发 | `MX-CUT-P-POW` | P 2.0–2.4；C 3–5 g/kg；E −300~−400 kcal | 强度不砍、辅助量 −20~30%；训练前 1–3h 碳水 1–2 g/kg；训练后碳水 1.0–1.2 g/kg/h |
| 速度 | `MX-CUT-P-SPD` | P 2.0–2.4；C 3–5 g/kg；速度日 E≥−300 kcal | 速度日不加深缺口；训练前 2–3h 碳水 1–2 g/kg |
| 保肌（原增肌） | `MX-CUT-P-HYP` | P 2.0–2.4；C 3–5 g/kg；E −300~−400 kcal | 仅保肌：不加量，力量维持 1–2 次/周；训练后蛋白 25–40 g |
| 有氧耐力 | `MX-CUT-P-END` | P 2.0–2.4；C≥3 g/kg；E −300~−400 kcal | 缺口≤400；大负荷日不加深；训练后碳水 1.0–1.2 g/kg/h |
| 肌耐力 | `MX-CUT-P-MEND` | `macros=null`（weak，条件格） | 仅维持现有容量，不新增循环/间歇课；缺口沿用 `B-CUT`（≤400） |
| 技战术 | `MX-CUT-P-SKL` | `macros=null`（weak） | 技术日不加深缺口；训练前少量碳水 |
| 减脂本体 | `MX-CUT-B-CUT` | P 2.0–2.4；C 3–5 g/kg；Fat 0.5–1.0；E −300~−600 kcal | 训练前后集中碳水；每 2–3 周 refeed |
| 控级别 | `MX-CUT-B-HOLD` | P 2.0–2.4；C 3–5 g/kg | 仅 `gapPct≤1.5%`；只维持不再减 |

组合配方：`C01`（爆发+减重）、`C04`（速度+减脂）、`C08`（耐力+减脂）、`C26`（减脂+保肌）、`C29`（减脂+肌耐力）。

### 2.2 三餐与训练前后怎么排

- **训练日**：不空腹上强度；训练前 1–3 小时吃主餐（碳水 1–2 g/kg）；训练后 2 小时内补蛋白 25–40 g；大负荷日训练后按 1.0–1.2 g/kg/h 补糖。
- **力量课后那一餐**：先保证 25–40 g 蛋白，再配碳水；不要只吃蛋白、把碳水全砍掉。全天碳水 3–5 g/kg，尽量集中在训练前后。
- **大负荷日**：缺口不加深；训练前和训练后各留一份碳水，不要把大负荷日的碳水压到下限以下。
- **速度日**：缺口不超过 300 kcal；训练前 2–3 小时吃 1–2 g/kg 碳水，选低纤维低脂。
- **技术日**：不加深缺口；训练前少量碳水，避免空腹。
- **休息日**：碳水可以取 3 g/kg 附近，但不要断碳；蛋白仍按 2.0–2.4 g/kg 分配。
- **refeed**：每 2–3 周安排 1–2 天，以碳水为主，脂肪不额外堆、酒精不碰；不是“随便吃一天”。

### 2.3 保肌要点

1. 蛋白 2.0–2.4 g/kg，分到 4–5 餐，每餐 0.3–0.4 g/kg；减脂期蛋白优先级高于碳水。
2. 力量训练每周 1–2 次，只维持、不加量；强度不砍，辅助量 −20~30%。
3. 缺口封顶 400 kcal；速度日不超过 300 kcal；大负荷日不加深。
4. 周降不超过 1% 体重（`wc-rate` / `PHASE-01`）；超过就加餐或回到维持 1–2 天。
5. 碳水集中在训练前后；训练后那一份碳水是保肌和保表现的工具，不是第一个被砍的项目。

### 2.4 什么信号出现就要加餐

- 周降 >1% 体重，或连续两周下降过快（`PHASE-01`）。
- 睡眠 <6.5 小时、酸痛 ≥7、晨脉 +5（`SLE-01` / `REC-02` / `REC-03`）。
- 力量或速度表现明显下降，且不是单次波动。
- EA <30 kcal/kg FFM（`G-EA`）：停止加深缺口。
- 持续饥饿、情绪差、训练提不起劲：先加训练前后碳水，再评估缺口是否过大。

加餐动作：优先加训练前后碳水；仍不够时回到维持能量 1–2 天，不要直接放弃减脂。

### 2.5 常见错误

- 用加练换更大的缺口。
- 先砍强度，再砍蛋白。
- 训练后只吃蛋白、不吃碳水。
- 周降超过 1% 还继续压。
- 把 refeed 执行成高脂高酒精的“欺骗餐”。

## 3. peak（微调期）

### 3.1 矩阵对应

| 当天课型 | 矩阵格子 | 宏量 | 策略 / 时机 |
|---|---|---|---|
| 力量 / 爆发 | `MX-PEAK-P-POW` | P 1.6–2.2；C 3–5 g/kg；E 0 | 只保强度、不加量；训练前 1–2h 小份碳水 |
| 速度 | `MX-PEAK-P-SPD` | P 1.6–2.2；C 3–5 g/kg；E 0 | 低容量保速度；训练前 2–3h 碳水 1–2 g/kg |
| 有氧耐力 | `MX-PEAK-P-END` | P 1.6–2.2；C 3–5 g/kg；E 0 | 只维持低容量，不新增负荷；按计划补液 |
| 肌耐力 | `MX-PEAK-P-MEND` | N/A | 微调期不做高容量肌耐力课；可延后 |
| 技战术 | `MX-PEAK-P-SKL` | `macros=null`（weak） | 低纤维、低体积；技术课为主 |
| 水盐微调 | `MX-PEAK-B-PEAK` | P 1.6–2.2；C 3–5 g/kg；E 0 | 只动水、钠、纤维与胃肠内容物；按补液计划；快碳≤60 g/h |
| 睡眠 | `MX-PEAK-G-SLE` | — | 目标 7–9h；<7h amber；固定作息 |
| 胃肠 | `MX-PEAK-G-GI` | — | 低纤维、低脂、小体积；快碳≤60 g/h |

`MX-PEAK-P-HYP`、`MX-PEAK-B-CUT`、`MX-PEAK-B-HOLD`、`MX-PEAK-B-GAIN`、`MX-PEAK-B-REFUEL` 均为 N/A。组合配方：`C14`（微调+胃肠）、`C15`、`C25`。

### 3.2 三餐与训练前后怎么排

- **训练日**：只做低容量、高强度；训练前 1–2 小时吃小份碳水（力量/爆发），速度课按 2–3 小时吃 1–2 g/kg 碳水；训练后按常规蛋白，不额外堆碳水。
- **餐次结构**：低纤维、低脂、小体积；蔬菜选可溶性纤维、去皮去籽，避免大份粗粮和油炸。
- **补液**：按补液计划执行，不临时加量；快碳≤60 g/h；出汗多的训练补含钠液体（`hyd-replace` 的 300–700 mg/L）。
- **赛前 24–48 小时**：才按 `carb-fightweek` 把碳水提到 8–10 g/kg；减量周本身不做碳水负荷。
- **赛前一周**：不试新食物、不试新补剂；所有餐次按已经验证过的组合重复。

### 3.3 保肌 / 保能力要点

1. 能量为 0：不做缺口、不做盈余；`B-CUT` / `B-HOLD` / `B-GAIN` 在 peak 列都禁止。
2. 蛋白 1.6–2.2 g/kg，按平时习惯分配；不要临时大幅加蛋白。
3. 碳水 3–5 g/kg；减量周训练量下降，但碳水不跟着砍。
4. 只动水、钠、纤维和胃肠内容物；这是 peak 唯一允许的调整维度。
5. 强度保留、容量下降；不做“补课”式加练。

### 3.4 什么信号出现就要调整

- 补液计划执行率 <80%（`HYD-05`）：先补执行，不临时改计划。
- 胃肠症状 ≥2/4 或呕吐（`GI-01`）：减纤维、减体积、减脂肪，回到已验证食物。
- 睡眠 <7 小时（`SLE-01`）：固定作息，不靠午睡补。
- 体重偏离计划：先看水盐执行，不要临时加缺口或加碳。

### 3.5 常见错误

- 把减量周当成减碳周。
- 赛前一周临时试新补剂、新食物。
- 用减量周“补课”加练。
- 大份高纤维、高脂餐。
- 只补水不补钠，或短时间灌大量水。

## 4. recover（恢复期）

### 4.1 矩阵对应

`MX-RECOVER-P-POW`、`P-SPD`、`P-HYP`、`P-END`、`P-MEND`、`P-SKL`、`B-CUT`、`B-HOLD`、`B-GAIN`、`B-PEAK` 全部 N/A；唯一合法的是 `MX-RECOVER-B-REFUEL`。

| 格子 | 宏量 | 策略 / 时机 |
|---|---|---|
| `MX-RECOVER-B-REFUEL` | P 1.6–2.0；碳水两段：轻度限制 4–7 g/kg、糖原耗尽 8–12 g/kg；7–8 不合法；E 0 | ORS + 快碳 + 蛋白；逐步加纤维；先补液再补糖；快碳≤60 g/h；蛋白与碳水同餐 |
| `MX-RECOVER-G-SLE` | — | 恢复期优先睡眠 |
| `MX-RECOVER-G-GI` | — | 低纤维起步，逐步加回 |
| `MX-RECOVER-G-EA` | — | 恢复期不判 EA |

组合配方：`C16` / `C17`（先恢复，再谈增肌或控重）。

### 4.2 补液与进食怎么排

1. **先补液**：称重后前 2 小时至少补 1000 ml（`HYD-04`：<1000 ml amber，<500 ml red）；按每流失 1 kg 补 1.25–1.5 L 含钠液体，分次喝（`hyd-replace` / `wc-weighin-recovery`）。
2. **再补糖**：先定总碳水段：轻度限制 4–7 g/kg，糖原耗尽 8–12 g/kg；7–8 g/kg 不合法；快碳≤60 g/h（矩阵 `B-REFUEL`）。
3. **蛋白同餐**：蛋白 20–40 g 与碳水同一餐，不要只喝糖水（`wc-weighin-recovery`）。
4. **纤维逐步加**：第一餐低纤维、易消化；胃肠耐受后再加蔬菜和粗粮（`GI-01`）。
5. **24 小时目标**：体重回升至少 50% 的失重（`REC-04`）；`wc-weighin-recovery` 的“12h 恢复 3–5% 体重”是另一表述，冲突时以 `REC-04` 规则为准。

### 4.3 保肌要点

1. 恢复窗只有 12–24 小时，不是掉肌的主战场；这一窗不做减脂、控重或增肌决策。
2. 蛋白 1.6–2.0 g/kg，20–40 g/餐，与碳水同餐；能量为 0，不制造缺口。
3. 真正的停训掉肌属于 `rehab`：按 `RH-01`（能量别马上砍、蛋白先给足）、`RH-03`（缺口调小）、`RH-04`（肌肉掉得比脂肪快）处理。
4. 恢复期不排训练课；想“补练”会把补液补糖的窗口挤掉。
5. 睡眠优先；恢复期不判 EA。

### 4.4 什么信号出现就要调整

- 称重后 24 小时体重回升 <50%（`REC-04`）：加补液和碳水，检查是否还在限制。
- 晨尿颜色 ≥5/8（`HYD-03`）：继续补液，不要只喝白水。
- 胃肠症状 ≥2/4（`GI-01`）：减纤维、减体积、分餐。
- 仍在本能地“控重”（继续称重、继续算缺口）：先停掉这些行为，恢复期不做这些决策。

### 4.5 常见错误

- 称重后继续减重或继续控重。
- 只喝白水，不补钠。
- 一次灌大量液体或一顿吃太多。
